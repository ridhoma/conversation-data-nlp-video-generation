# Data

The datasets are **not committed to this repository**. Download them separately and place them here.

## Download

**[Download the data from Google Drive »](https://drive.google.com/drive/folders/1FJce-dASltwKtQJzquCbtv58BgaZ3sp6)**

After downloading, arrange the files so this folder looks like:

```
data/
├── raw/                  # original, untouched CSVs
│   ├── messages.csv
│   ├── users.csv
│   └── videos.csv
└── processed/            # cleaned + NLP-enriched outputs (produced by the notebooks)
    ├── messages.csv
    ├── users.csv
    ├── videos.csv
    ├── conversations.csv
    ├── user_messages_intent.csv
    ├── create_intent_messages_anatomy.csv
    ├── repetition_scored.csv
    ├── unique_user_messages_content.csv
    ├── golden_set_intents.csv
    └── golden_set_brief_checklist.csv
```

Only the three files under `raw/` are strictly required to start — everything in `processed/`
is regenerated by running the notebooks (`01` → `02` → `03`) in order. The download bundle
includes the pre-computed `processed/` files so you can skip the slow NLP inference step if you
just want to explore the analysis.

## Raw schema

| Table | Rows | Key fields |
|-------|------|-----------|
| `messages.csv` | ~15K | `message_id`, `conversation_id`, `user_id`, `video_id`, `role`, `content`, `model`, `timestamp` |
| `videos.csv` | ~2K | `video_id`, `creator_id`, `conversation_id`, `created_at`, `generated_at`, `published_at`, `downloaded_at` |
| `users.csv` | ~225 | `user_id`, `workspace_id`, `plan`, `created_at`, `country` |

Paths are resolved from the repo root via `nlp/paths.py` (`RAW`, `PROCESSED`), so the notebooks
find these files regardless of the working directory.
